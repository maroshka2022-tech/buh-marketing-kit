# buh-marketing-kit

Набор для **Claude Code**, который помогает экспертам-бухгалтерам и онлайн-школам вести контент:

- `/post` — пишет пост для Telegram и Max по новости, теме или тексту закона;
- `webinar-funnel` — скилл, который собирает воронку вебинара: расписание и тексты писем и сообщений от приглашения до дожима.

Финальный проект курса по работе с Claude Code в терминале. Без кода и зависимостей: только Markdown-файлы с промтами.

## Что умеет

### Команда `/post`
На вход — новость, тема, ссылка или текст закона. На выходе — пост для канала предпринимателей (ИП, ООО, МСП) от имени эксперта-бухгалтера:
- цепляющий заголовок;
- суть простыми словами;
- что это значит для бизнеса и кого касается;
- что сделать (2–4 шага);
- мягкий призыв к обсуждению.

Сразу три варианта длины: короткий, стандартный и развёрнутый. Эмодзи умеренно, форматирование подходит для Telegram и Max.
**Ничего не выдумывает:** цифры, даты и нормы берутся только из исходного текста, а всё, чего нет в источнике, помечается `[проверить: …]` и выносится в чек-лист.

### Скилл `webinar-funnel`
По теме, дате и времени эфира, аудитории, продукту и подарку за регистрацию собирает воронку:
- приглашения;
- подтверждение регистрации с подарком;
- прогревы;
- напоминания: за сутки, за 3 часа, за 15 минут, «мы в эфире»;
- спасибо и запись, повтор;
- дожимы после эфира (если есть продукт).

Результат — таблица-расписание и готовые тексты для email и мессенджеров. **Цены, скидки и отзывы не придумывает:** вместо них плейсхолдеры `[ЦЕНА]`, `[ДЕДЛАЙН]`, `[ССЫЛКА_НА_РЕГИСТРАЦИЮ]` и т. д.

Скилл срабатывает сам, когда вы просите «собери воронку вебинара». Его также можно вызвать командой `/webinar-funnel` или короткой `/funnel`.

## Для кого
- Бухгалтеры и налоговые консультанты, которые ведут Telegram или Max-канал.
- Онлайн-школы и эксперты, которые проводят вебинары и автовебинары.
- Все, кто учится Claude Code и хочет посмотреть, как устроены команды и скиллы.

## Установка

**1. Скачайте проект**

```bash
git clone https://github.com/<ваш-логин>/buh-marketing-kit.git
cd buh-marketing-kit
```

Или на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив.

**2. Выберите, как пользоваться**

- **Прямо в этой папке.** Ничего копировать не нужно: запустите Claude Code в папке проекта, команды подхватятся из `.claude/`.
- **В своём проекте.** Скопируйте папку `.claude/` в корень своего проекта (если там уже есть `.claude/`, скопируйте только `commands/` и `skills/`).
- **Глобально, для всех проектов.** Скопируйте содержимое в домашнюю папку:

```bash
mkdir -p ~/.claude/commands ~/.claude/skills
cp .claude/commands/*.md ~/.claude/commands/
cp -r .claude/skills/webinar-funnel ~/.claude/skills/
```

## Запуск

Откройте терминал в папке проекта и запустите Claude Code:

```bash
claude
```

Если Claude Code у вас подключён к моделям через **Ollama**, запустите его так, как настраивали на курсе. Например, в Ollama v0.15+ есть команда, которая сама настраивает и запускает Claude Code:

```bash
ollama launch claude
```

Подробнее — в [документации Ollama по Claude Code](https://docs.ollama.com/integrations/claude-code). Для работы с файлами и скиллами выбирайте модель с поддержкой инструментов (tool calling) и контекстом от 64K.

Проверить, что всё подхватилось: наберите `/` — в списке должны появиться `post`, `funnel` и `webinar-funnel`.

## Как это устроено

- **Команда** — Markdown-файл в `.claude/commands/`. Имя файла становится командой (`post.md` → `/post`), текст после команды подставляется на место `$ARGUMENTS`. Во frontmatter: `description` (что делает) и `argument-hint` (подсказка к аргументам).
- **Скилл** — папка в `.claude/skills/` с файлом `SKILL.md`. Claude читает `description` и сам решает, когда подключить скилл. Подробные материалы (`reference.md`, шаблоны) загружаются только при необходимости.

Документация: [Claude Code — Skills](https://code.claude.com/docs/en/skills).

## Важно
Тексты — черновики. Перед публикацией проверяйте все пометки `[проверить]` и сверяйте нормы с первоисточником (сайт ФНС, КонсультантПлюс, Гарант).
